# 契約審査・契約運用の後工程 / 01_overview

    ## ビジョン
    契約を締結の瞬間で終わらせず、義務履行と逸脱検知まで一貫して管理する。

    ## このドメインをどう見るか
    この領域の本質は、**書類やフォームを処理すること**ではない。  
    本質は、**意思決定に必要な正当性・証拠・ルール適合性・責任所在を、期限内に接続すること**である。

    したがって本テーマは、単なる自動化ツールではなく、次の問いに答える業務基盤として捉える。

    - いま何の案件が動いているか
    - その案件はどの規則・契約・証拠に拘束されるか
    - 次に誰が何をすべきか
    - 何が例外で、何が通常か
    - 顧客価値は「処理件数」ではなく、どの結果改善で測るべきか

    ## 対象ドメイン
    契約AIはドラフト比較に偏りがちだが、実務負荷が大きいのは締結後の更新監視、義務条項履行、相手先別逸脱、稟議条件との差分、監査対応である。

    ## 顧客と受益者
    - **一次顧客（予算保持者）**: 法務部、調達、営業企画、事業部管理、CLM導入済み大企業、契約BPO
    - **現場受益者**: 業務担当者、管理者、監査/統制担当
    - **最終受益者**: エンドユーザー、患者、取引先、契約者、発注者など、処理遅延や品質ばらつきの影響を受ける当事者

    ## 顧客が利益を被るメカニズム
    更新漏れ防止、義務履行の見える化、営業/調達/法務の分断解消、逸脱検知、監査・証跡整備

    重要なのは、「1人の作業を軽くする」だけで終わらないことだ。  
    このドメインでは、遅延や不整合が **売上、資金化、顧客体験、規制対応、監査対応** に波及する。  
    だからこそ、プロダクトの価値は UI の便利さではなく、**業務のボトルネックを外せるか** で決まる。

    ## なぜ10億円級が狙えるか
    Financial Times は 2022年時点の CLM 市場を約15億ドルと紹介し、生成AIにより再評価が進んでいると報じた。2026年には複数調査で 30億ドル超の市場推計が出ている。Ironclad は 2026年に ARR 2億ドル超を公表しており、カテゴリ自体の需要は強い。[R1][R2][R3]

    ## 主要アクター
    - **法務担当**: 標準条項・逸脱審査・訴求点管理
- **事業部オーナー**: 契約履行責任
- **調達/営業**: 取引条件の一次交渉
- **相手方**: 契約相手先
- **監査/内部統制**: 履行状況・証跡確認

    ## 提供するべきプロダクトの姿
    この領域では、チャットUIや文書要約だけでは不十分である。必要なのは以下を備えた「業務OS」である。

    1. 案件・ケースの集約
    2. ルールと証拠の接続
    3. 例外の検知と優先順位付け
    4. 関係者へのアサインと追跡
    5. 監査証跡と再現性
    6. 学習ループ（過去案件を次回運用へ還元）

    ## 本資料におけるプロダクト方針
    - ドメイン用語を先に定義し、実装詳細は後ろに置く
    - 生成AIは一部機能であり、中心はケース運用と状態管理
    - 既存基幹システムを置き換えるより、**既存システム間の高摩擦部分を支配する**
